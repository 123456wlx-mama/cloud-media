# 08 界面设计契约（Qt 客户端）

> 版本：P8-0（2026-10-20）｜ 适用：`client/ui/` 全部界面代码
> 上位文档：docs/specs/06-业务设计.md（协议与时序）、docs/specs/01-架构设计.md（分层红线）
> 视觉基线实现：`client/ui/app.qss`（本文件 §4 是唯一色板来源，改色先改这里）

## 0. 范围与非目标

**做**：登录 → 文件列表 → 上传/下载（含断点续传）→ 分享 → 在线播放，单窗口三段式。

**不做**（需求已冻结，界面不得预留入口）：多端同步、Office/PDF 预览、会员/容量、团队空间、
离线下载、多清晰度转码、AI 摘要；**重命名/移动**（协议只有软删/恢复，没有 RenameRq/MoveRq，
不为界面发明协议）；播放器不做字幕/弹幕/投屏/画中画/选集/连播。

## 1. 信息架构

### 1.1 窗口结构

~~~text
LoginDialog（模态，380×420）
    │ 登录成功
    ▼
MainWindow（1280×800，可拖拽三分栏 QSplitter）
┌──────────────┬────────────┬──────────────────────┐
│ 文件区(5)     │ 传输区(3)   │ 播放区(4)             │
│ 面包屑+工具栏 │ 上传/下载Tab│ 画布 + 控制条         │
│ QTableView   │ 任务列表    │ 空态 / 播放 / 缓冲     │
└──────────────┴────────────┴──────────────────────┘
   状态栏：登录态 · 连接态 · 当前任务数 · 限速提示
~~~

### 1.2 各区职责

| 区 | 职责 | 不做什么 |
|---|---|---|
| 文件区 | 目录浏览（面包屑 + 分页）、上传入口、右键菜单（下载/分享/删除）、拖拽入队 | 不放全局设置、不放播放控制；**不做重命名**（协议无 RenameRq，见 §0） |
| 传输区 | 上传/下载任务队列、实时进度与速度、暂停/继续/取消、失败重试、断点续传入口 | 不直接播放、不删远端文件 |
| 播放区 | 选中视频起播（边下边播）、缓冲与错误提示、全屏 | 不做文件管理 |
| 登录对话框 | 手机号+密码、错误行、注册入口 | 不做找回密码（非目标） |

### 1.3 联动关系（必须遵守的单向数据流）

1. **点文件 → 播放区起播**：文件区双击视频 → 发 `PlayReportRq` 前先 `DownloadOpenRq` 拿 ticket → 播放区显示"缓冲中"→ 首块到达后起播。
2. **上传/下载任务 → 传输区**：任务状态只由 `transfer` 层（队列/状态机）驱动，界面**只读**；界面不得自己算进度。
3. **传输完成 → 文件区刷新**：上传 `UploadCompleteRs.code=0` → 文件区插入新行（不整表刷新，避免闪烁）。
4. **删除/分享 → 传输区**：删除不取消正在跑的任务（先提示"该文件正在传输"）；分享只对已完成文件可用。
5. **限速生效提示**：下载速度长期贴 2MB/s 时，状态栏右侧显示"已限速 2MB/s（连接级）"，避免用户误判为故障。

## 2. 交互流程（全链路）

### 2.1 主流程状态图

~~~text
[未登录] --输入手机号/密码--> [登录中] --LoginRs.code=0--> [已登录/列表加载]
                                  │ code=2001/2004 → 错误行"手机号或密码错误"
                                  │ code=4007      → 错误行"服务暂不可用，请稍后重试"
                                  └ 网络失败        → 错误行"连接失败，检查网络" + 保持可重试

[已登录/列表加载] --ListFileRs--> [列表就绪] --空 items--> [空列表态]
                                     └ 失败 → [列表错误态]（重试按钮）

[列表就绪] --点"上传"/拖入文件--> [秒传预检 UploadInitRq]
      ├ result=1（秒传命中） --> 传输区显示"已秒传 · 0 字节"（3s 后淡出）→ 文件区插入
      └ result=0            --> [分片上传] --> [合并中] --CompleteRs-->
              ├ code=0                    → [完成]
              ├ code=1001 + badIndexes>0  → [坏片重传]（只重传 badIndexes）
              └ code=3003/3007            → [失败可重试]（重新 init）

[列表就绪] --右键"下载"--> [DownloadOpenRq] --ticket--> [分块下载]
      ├ 本地已有 .part.state 且 size/md5 一致 → [断点续传]（只取缺块）
      └ 无 state                              → [全新下载]
      [分块下载] --每块--> 进度条/速度 --全部块--> [DownloadDoneRq] --> [完成]
                 └ 失败/断网 → [暂停]（state 落盘）→ 用户"继续" → 重新 open + 续传

[列表就绪] --右键"分享"--> [ShareCreateRq] --shareCode--> 弹窗展示"复制链接/提取码"
[任意]    --"打开分享"--> [ShareOpenRq] --shareTicket--> 下载（走同一套传输区）
~~~

### 2.2 关键交互细则

| 场景 | 规则 |
|---|---|
| 上传并发 | 默认 2 个文件并发，单文件 2 个分片在途（服务端每连接上限），超出排队 |
| 下载并发 | 单文件默认 4 连接（服务端上限 8），全局并发文件 2 |
| 秒传 | **必须显式提示**"已秒传"，否则用户会以为没上传 |
| 断点续传 | 续传前必须用 `DownloadStatRq` 比对 size + md5；不一致则整文件重下并提示"文件已变更" |
| 分享 | 生成后弹窗给"分享码 + 提取码 + 过期时间"，一键复制；提取时错误码 2003/2004 分别提示"已过期"/"提取码错误" |
| 播放 | 边下边播：首块（4MB）到达即起播；缓冲 < 2s 不显示 loading，避免闪烁 |
| 删除 | 软删进回收站，Toast 提示"已移入回收站 · 撤销"（撤销调 RestoreRq） |

## 3. 状态与空态

| 状态 | 触发 | UI 表现 |
|---|---|---|
| 未登录 | 启动 / 断线登出 | 登录对话框；主窗口不出现 |
| 列表加载中 | ListFileRq 发出 | 表格区骨架占位（3 行灰条）+ 顶部细进度条，**不遮罩** |
| 空列表 | items.size()=0 | 居中：图标 + "还没有文件" + 主按钮"上传文件"（空态必须带可执行动作） |
| 列表错误 | 协议错误/网络错误 | 居中："加载失败 · {原因}" + "重试"；保留旧数据不清空 |
| 传输中 | 任务 running | 行内进度条（6px）+ 速度（如 2.0 MB/s）+ 剩余时间；行尾"暂停/取消" |
| 暂停 | 用户暂停 / 断网 | 进度条变 @warning 色、速度显示"—"、按钮变"继续"；断网时附"网络已断开" |
| 失败可重试 | 错误码或 IO 失败 | 行变 @danger 边、显示错误摘要（如 "服务端拒绝 3003 校验失败"）、按钮"重试" |
| 秒传命中 | UploadInitRs.result=1 | 任务行绿色勾 + "已秒传 · 0 字节"，不显示进度条 |
| 播放缓冲 | 首块未到 / seek 未就绪 | 画布中心转圈 + "缓冲中"（<2s 不显示） |
| 播放失败 | 解码失败 / 文件损坏 | 画布内居中："无法播放该文件" + "用系统播放器打开"（明确降级出口） |
| 断线重连 | 网络线程检测到断开 | 状态栏黄点 + "连接已断开，正在重连(3/5)"；传输任务全部转"暂停" |

`text-3` 只用于非关键信息（空态/禁用），不承载必须读到的内容。

### 4.2 字号阶梯

| 级别 | 字号 | 用途 |
|---|---|---|
| Display | 24px / 600 | 登录页品牌名 |
| Title | 14px / 600 | 分区标题、对话框标题 |
| Body | 13px | 正文、表格、按钮 |
| Body-strong | 14px / 600 | 主按钮文字、登录输入 |
| Caption | 12px | 状态栏、辅助说明、错误行 |
| Badge | 11px | 数量徽标（如"3 个任务"） |

行高：表格行 36px；分区头 36px；按钮高 32px；输入框高 38px；任务行 56px（两行内容）。

### 4.3 间距与圆角

- 间距基数 **4**，只用 4 / 8 / 12 / 16 / 24 / 32；面板内边距 12，对话框 32（左右）/36（上）。
- 圆角：控件 **6px**，卡片/弹窗 **8px**，进度条与徽标 **3px**。
- 分割线一律 1px `border`；不使用阴影（深色主题下阴影脏），靠 1px 描边分层。

## 6. 与 legacy 对照

| 功能面 | legacy（wanpan-dome/client） | 新实现 | 处置 |
|---|---|---|---|
| 登录 | `logindialog.ui` + `CKernel` 登录分支 | `LoginDialog` + `LoginRq/LoginRs` | **保留交互**，协议换 v2 |
| 文件列表 | `maindialog.ui` + `QTableWidget` + `mytablewidgetitem` | `QTableView` + `QAbstractTableModel` | **替换**（Model/View，禁手填 item） |
| 上传 | `packdef.h` 手写帧 + 单连接顺序传，无断点 | `transfer/` 任务队列 + init/chunk/complete + 坏片重传 | **重写** |
| 下载 | 同上，无分块并发 | 4 连接分块 + `.part.state` 续传 + 服务端限速 | **重写** |
| 分享 | 仅分享码输入框 | `ShareCreate/ShareOpen` + 提取码 + 过期时间 | **扩展** |
| 重命名 | legacy 无独立入口 | — | **删除**（非目标：协议无 RenameRq，界面不留入口、不造协议） |
| 网络 | `TcpClient`/`INet` 回调 + WinSock HANDLE | `QTcpSocket` + 独立网络线程 + 信号槽 | **替换**（禁 WinSock） |
| 本地缓存 | `csqlite` 手写 SQL 拼串 | `sqlapi/`（SQLite 封装，预编译语句） | **重写**（禁拼串） |
| UDP | `UdpNet` / `UdpMediator` | — | **删除**（业务无 UDP） |
| 内嵌服务端 | `TcpServer` / `TcpServerMediator` | — | **删除**（客户端不监听端口） |
| 头像图片 | `face/*.png`（100+ 张） | 首字母圆形徽标（纯 QSS） | **删除**（非目标，减体积） |
| 协议分发 | `PFUN` 函数指针数组 | `std::unordered_map<int, std::function<...>>` | **替换**（C++11 规范） |

## 7. 落地约束

1. **纯 C++11**：禁 `std::make_unique` / optional / string_view / filesystem / 泛型 lambda（与 server 同规范）。
2. **依赖红线**：`client/` 不得 include `server/`；`common/` 不得出现任何 Qt 符号（CI grep 卡）。
3. **QSS 唯一来源**：颜色只能来自 §4.1；新增颜色必须先改本文件再改 `app.qss`。
4. **32 位一致性**：Qt 5.12.11 `mingw73_32` 是 32 位，后续内嵌 FFmpeg/SDL 必须同为 32 位（见 phase-8.md §环境）。
5. **界面不做业务**：所有网络/落库/状态机在 `netapi/transfer/sqlapi/player`，`ui/` 只做展示与转发。
