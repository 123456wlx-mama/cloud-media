## 0. 30 秒速览

**一句话**：Windows Qt 客户端 + Linux 自研 Reactor 服务端的云盘与在线播放系统 —— 二进制协议 v2、内容寻址存储，支持秒传、断点续传、分享转存、回收站、边下边播。

| 项 | 内容 |
|---|---|
| 服务端 | C++11 · epoll(ET + ONESHOT) · 自研线程池 · MySQL 8 · Redis 7 · sendfile |
| 客户端 | Qt 5.12(32 位) · QTcpSocket 独立网络线程 · FFmpeg 4.2.2 · SDL2 音频 |
| 存储 | 内容寻址 `data/blobs/aa/bb/{md5}` + `t_file.f_ref_count` |
| 规模 | 253 个源文件 / 44,882 行（common 6.6k · server 27.5k · client 10.8k）；文档 38 篇 / 10.6k 行 |
| 测试 | 服务端 ctest **44 项**（含 MySQL/Redis 集成）· 客户端 5 套（netapi/transfer/sqlapi/flow/ui） |
| 关键数字 | 上传 **86.7 MB/s** · 下载裸能力 **522 MB/s**(CPU 15%) · 列表 **4310 QPS** · 8000 长连接 RSS **41.7MB** |

**已知边界（面试主动说，别等人问）**

- HLS Remux 未落地（`server/media/` 只有 .gitkeep）；播放只做直链边下边播；
- 不支持目录转存（只单文件）、不支持目录级联软删（彻底删除才级联）；
- 无容量配额/会员体系；播放记录单端；不做重命名接口；不做字幕/弹幕/投屏/多清晰度。

## 3. 协议号速查

**帧头 19 字节**：魔数 `CMDV`(4) + VERSION(1) + TYPE(2) + LEN(4) + SEQ(4) + CRC32(4)，后接 payload（普通帧上限 8MB；10006 走 bulk 路径）。
**CRC32 覆盖**：`VERSION..SEQ` 11 字节 + payload（**不含魔数与 CRC 自身**）。

| 业务 | 类型号 | 备注 |
|---|---|---|
| 认证 | 10000/10001 注册、10002/10003 登录 | 登录只回 uid + 昵称，不回显哈希/salt |
| 上传 | 10004/10005 初始化、10006/10007 分片（**4MB bulk**）、10030/10031 触发合并 | 10004 命中秒传直接回 result=1 |
| 秒传/续传 | 10017/10024 秒传预检、10028/10029 **续传位图** | 续传靠位图，不靠文件长度 |
| 目录 | 10008/10009 列表（keyset 分页）、10015/10016 新建文件夹 | 禁用 OFFSET |
| 下载 | 10010/10012 打开、10027/10014 续传校验、10013/10011 取块（**bulk**）、10040/10041 完成 | 10012 内含 ticket（Redis 10min） |
| 分享 | 10018/10019 创建、10020/10021 我的分享、10022/10023 访问、10042/10043 取消、**10044/10045 转存** | 转存只加引用，不搬字节 |
| 回收站 | 10025/10026 软删、10034/10035 列表、10036/10037 恢复、10038/10039 彻底删除 | 彻底删目录会级联 |
| 播放 | 10032/10033 进度上报 | |
| 控制 | 11000 Hello、11002 ErrorRs、11003/11004 心跳、11005 Logout | 9007 = 类型退役 |

## 4. 表速查

| 表 | 一句话 | 关键约束 |
|---|---|---|
| `t_user` | 账号 | `u_tel` 唯一；密码 = 哈希 + salt + algo |
| `t_user_file` | 用户目录树（"我的文件"） | `uf_parent_id=0` 根；目录 `f_id=NULL`；`uf_deleted_at` 1970 哨兵=未删；唯一键含该列以容纳同名重传 |
| `t_file` | 内容寻址 blob | `f_md5` 唯一；`f_ref_count` 引用计数；`f_state` 0上传中/1就绪/2孤儿/3缺失 |
| `t_transfer_task` | 写侧任务（上传/转存/秒传） | `tr_type` 1/2/3；`tr_status` 0待/1进行/2暂停/3失败/4完成/5取消/6过期；`tr_expire_at` |
| `t_chunk` | 分片 | 主键 `(c_task_id,c_index)`；`c_md5` 是**分片 MD5**；`c_state` 0写中/1完成（fsync 后置 1） |
| `t_share` | 分享 | `s_code` 6 位（31 字符表去易混）；`s_access_code` 4 位；`s_status` 0有效/1取消；`s_expire_at` |
| `t_play_record` | 播放进度 | `(p_user_id,p_file_id)` 一条，LWW 覆盖 |

## 5. 十条关键决策（面试主战场：决策 → 为什么 → 代价）

| # | 决策 | 为什么 | 代价/边界 |
|---|---|---|---|
| 1 | Reactor + epoll **ET + ONESHOT** | ET 少触发；ONESHOT 强制"处理完再注册"，避免同一连接被多线程并发读 | 写完必须手动重注册，漏了会"卡住不动" |
| 2 | 协议 v2 自带**魔数 + CRC32** | 坏包在解码层就被拒，业务层只见完整帧；强制升级不兼容 v1 | CRC 要算 payload，大帧必须挪出 IO 线程 |
| 3 | **内容寻址 + 引用计数** | 一份物理文件多用户/多路径共用，零副本 | 引用计数必须在事务内维护，否则漏减/多减 |
| 4 | **秒传** | MD5 命中直接建节点，0 字节传输 | 必须 UI 显式提示，否则用户以为没上传 |
| 5 | 断点续传用**位图** | 服务端按 `t_chunk` 生成位图，客户端 `.part.state` 记已下块，只补缺 | 块粒度 4MB，最坏重传 4MB |
| 6 | **令牌桶 + 流数上限** | 连接级 2MB/s、用户级 8MB/s、全局 512 流，超限回 3006 | 令牌不足用定时器延迟，**绝不 sleep 工作线程** |
| 7 | **sendfile 零拷贝** | 数据全程内核态，10MB 下载裸能力 522MB/s、CPU 15% | 需要块 CRC sidecar + `crc32Combine` 才能同时满足校验 |
| 8 | **异步日志** | 工作线程只入队，后台线程落盘 | 崩溃时可能丢最后几条 |
| 9 | 音画同步**以音频为主时钟** | 声卡时钟不可控，视频按 pts 差等待/丢帧；无音频退回系统时钟 | 设备不支持音频时要能退化 |
| 10 | **C++11 红线** | 不用 `make_unique`/`optional`/`string_view`/`filesystem`，老工具链可编 | 写起来啰嗦（`new` + 手工 delete） |

## 7. 性能数字与口径（答辩必背）

| 指标 | 数值 | 口径/条件 |
|---|---|---|
| 上传吞吐 | **35.3 → 86.7 MB/s（2.46×）** | 10MB × 100 并发、64 在途、2C4G 回环；优化项 O7-c + O1 |

## 8. 故障演练清单（面试最加分）

1. 传到一半 `docker compose stop server` → 客户端「重连中(第N次)」持续退避；重启后 ≤8s 自动连回并重登；任务保持「暂停」，点继续续传。
2. 上传到一半 kill 客户端进程 → 重开客户端，任务以「已暂停」恢复，从服务端位图续传（只补缺块）。
3. 手工改坏一个分片文件 → 合并时逐片 MD5 校验发现坏片，只重传 `badIndexes`。
4. 删除正在播的文件的云端节点 → 播放不受影响（本地 `.part` 还在），但重新点播会 404。
5. 删文件夹（里面还有上传任务）→ 弹"内还有 N 个文件正在上传"二次确认。
6. 分享被取消后刷新访问 → 命中缓存失效 → 回源得 2003（已过期/取消）。
7. 同一分享保存两次 → 命中「同名同 blob」直接复用（`reused=1`），不会堆副本、引用计数不变。
8. 把 Redis 停掉 → 元信息回源 MySQL（fail-open）；带提取码的分享回 4008（fail-closed）。
